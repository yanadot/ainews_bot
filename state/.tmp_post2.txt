OpenAI открыла для всех Decisions API — сервис, который отвечает на простые вопросы в 10 раз быстрее обычных моделей.

Это не чат-бот: API сразу выдаёт короткий ответ — вероятность, что утверждение верно, выбор варианта из списка или оценку по шкале. Принимает текст, фото и структурированные данные, до 400 вопросов за запрос. Работает на модели GPT-6 Luna. Цена — $0,10 за миллион входных токенов (с кешированием — $0,01), ответ бесплатен.

Пригодится для быстрой классификации: искать брак на фото товара, распределять жалобы клиентов по отделам, оценивать серьёзность багов. Есть голосовой режим — модель реагирует по ходу разговора, ещё до того как человек договорит.

После гонки за самыми умными моделями индустрия переходит к оптимизации скорости и цены для рутинных задач. Для продуктовых команд это шанс встроить классификацию там, где AI раньше был слишком дорогим или медленным.
